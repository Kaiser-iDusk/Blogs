# 📝 Blog Repository

A lightweight static blog built with pure HTML and CSS. Simple, fast, and easy to maintain.

## 📂 Structure

```
.
├── index.html          # Main blog landing page
├── assets/
│   └── styles.css      # Styling
└── posts/              # Blog post content
```

## 📤 Publishing

This repository uses the **[Blog Management System](https://tinyurl.com/yc7yb9am)** for deployment.

Push your changes to deploy the blog automatically.

## 📋 Features

- ⚡ Static HTML - No server required
- 🎨 Custom CSS styling
- 📱 Lightweight and fast
- 🔧 Easy to customize
