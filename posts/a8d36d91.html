My Blog Management System [Part 1]

Hi everyone! In this blog I will discuss with you my Blog Management System. The idea employed here is not unique but still the implementation is a bit tricky. So I shall split it into 2 blogs.

Core Design:

The system stores all the blogs in Github and renders them through Github Pages. This solves the primary issue of storage since all the rendered markdown is converted into static HTML files.

Now the next thing is the backend. I chose Flask simply because this is a light-weight web app and I am more comfortable in Python than in JavaScript. I added a few common functionalities like login/signup but they are not the topic of discussion today.

I used Jinja2 templates to inject the markdown from the editor into a base template and that serves as the static HTML file.

Finally a script to automate the git push was written, and it handles all the deployment process. As you might have guessed this part is carried out by spawning a thread otherwise the UI would have hung up.

To sum up the core ideas are quite simple and the technology stack used is also quite familiar to everyone. But integrating them and debugging the errors was where the tricky part lies and it is not something which I can share through a blog.

Honestly speaking a large part of the UI components like HTML and CSS was generated with the help of ChatGPT. Other LLMs also helped in debugging the error logs of gunicorn when I deployed the backend on AWS EC2 and I am really grateful that such technologies exist nowadays.
